# Планер Лизика

Календарь со сроками сдачи, идеи и заметки: Найдём предков, Редактура, Учёба, Личное, Здоровье.
Записи синхронизируются через приватный репозиторий `planer-lizika-data` (настраивается во вкладке «Настройки»).
Напоминания о делах и сроках приходят в Telegram (workflow `.github/workflows/remind.yml`).
