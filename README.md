# Планер Лизика

Календарь со сроками сдачи, идеи, заметки и документы: Найдём предков, Редактура, Учёба, Личное, Здоровье.
Записи и файлы документов синхронизируются через приватный репозиторий `planer-lizika-data` (настраивается во вкладке «Настройки»).
Напоминания о делах и сроках приходят в Telegram (workflow `.github/workflows/remind.yml`).
